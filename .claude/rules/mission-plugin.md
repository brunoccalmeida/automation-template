# Changes to the mission plugin

The mission is closed by the published version of the plugin (installed from GitHub, `autoUpdate: false`), not by the branch's; to try the branch's version, see [Try a change before it is published](../../plugins/mission/README.md#try-a-change-before-it-is-published). After the merge, the next session's [outdated-plugin warning](../../plugins/mission/README.md#warning-when-the-plugin-is-outdated) shows the update command; the merge chat does not read this rule.
